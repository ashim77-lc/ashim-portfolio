# Ashim Lamichhane — Portfolio

This is the personal portfolio site for Ashim Lamichhane, a Computer Engineering student exploring software development and AI. It presents current learning areas, contact information, and three clearly marked project placeholders for future work.

## Technologies

- HTML5 for the page structure and accessible navigation
- CSS3 for the responsive layout, color palette, and interactions
- Vanilla JavaScript for skill details, the copy-email action, and the current footer year

No frameworks, build tools, paid services, or external runtime dependencies are required.

## Run locally

Because this is a static site, it can be opened directly in a browser by opening `index.html`. For a local web server, run one of these commands from the project directory:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

The local server is useful for testing browser features such as the clipboard API, which may be restricted when a page is opened directly from a file.

## Customize the project placeholders

The three cards in the Projects section of `index.html` are intentionally not completed projects. When real work is ready to add:

1. Replace the placeholder heading and description with accurate details about the project.
2. Update the `FUTURE PROJECT` label and `PLACEHOLDER` status so they describe the real project.
3. Replace `Details coming later` with a real project link only when that link exists.
4. Update the note below the cards if fewer than three placeholders remain.

Only add technologies, qualifications, experience, or outcomes that are accurate and can be supported.
